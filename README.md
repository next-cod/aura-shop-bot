# Aura Telegram Bot

Красный Telegram-бот для Minecraft-сервера Aura: магазин, обращения игроков и переход к Discord-заявкам.

## Что уже работает

- Каталог привилегий, пакетов Ауры и кейсов.
- Покупка через Telegram Payments после добавления токена платёжного провайдера.
- Сбор идей, баг-репортов и жалоб с пересылкой в закрытый staff-чат.
- Требование игрового ника перед оплатой и сохранение всех заявок/заказов в `data/aura-bot.json`.
- Привязка Telegram к Minecraft через текущий серверный bridge: игрок вводит `/link` в игре, подтверждает запрос в Minecraft и получает профиль в боте.
- Кнопка Discord для заявок на Helper, медиа-команду (YouTube/TikTok) и другие роли.

## Запуск

1. Откройте `aura-telegram-bot` и выполните `npm install`.
2. Скопируйте `.env.example` в `.env` и внесите значения.
3. Добавьте бота в закрытую группу администрации и укажите её ID в `STAFF_CHAT_ID`.
4. Запустите `npm run start`.

## Amvera

В проект уже включён `amvera.yml` для Node.js 24 и постоянного хранилища `/data`. В панели Amvera задайте секреты из `.env.example` в разделе «Переменные» — файл `.env` в репозиторий не загружается.

## Важно про оплату и выдачу

`PAYMENT_PROVIDER_TOKEN` выдаёт подключённый к BotFather платёжный провайдер. До его добавления бот честно направляет к магазину на сайте, а не создаёт фальшивую оплату. После оплаты бот фиксирует заказ и отправляет его в staff-чат. Автоматическая выдача в Minecraft намеренно не включена: для неё нужен отдельный защищённый API/плагин между ботом и сервером. Пока её нет, администратор выдаёт товар по нику из уведомления.

Для Minecraft-привязки добавьте в Amvera `AURA_TELEGRAM_API_URL` и `AURA_TELEGRAM_SECRET`: это адрес и секрет текущего bridge на VDS. Старый хост и VK-секрет бот не использует.

Цены кейсов и пакетов Ауры находятся в `src/catalog.ts`, а цены привилегий взяты из `AuraServerD/src/main/resources/config.yml`.
